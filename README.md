# 胡楚靓工作台

一个真正可用的创作者工作台网页应用，包含四个核心模块：每日任务、爆款热点/二创、内容复盘、每日灵感。

## 快速开始

```bash
cd /workspace/huchujing-workbench
python3 -m http.server 8000 --bind 0.0.0.0
```

然后在浏览器打开对应 URL 即可。

## 功能模块

### 1. 每日任务
- 当天任务、排期任务、例行任务三栏展示
- 预置「趁热打铁」三连击 + 每日例行
- 支持勾选完成、新增、删除

### 2. 爆款热点/二创
- 加载 `data/trends.json` 中的热点种子
- 按 6 个垂类标签筛选
- 显示「为什么适合我」和适配分
- 一键保存到「每日灵感」

### 3. 内容复盘
- 填写单条内容数据（播放、赞、评、转、完播、来源）
- 自动套用爆款方法论给出优化建议
- 历史复盘自动留存

### 4. 每日灵感
- 每天早上 9 点自动汇聚的选题
- 爆款模块可一键存灵感
- 支持手动增删

## 刷新热点数据

当前 `refresh_trends.py` 使用示例种子数据。接入真实抖音数据需要：
1. 获取抖音开放平台 / 巨量算数 / 热点宝的 API token
2. 修改 `fetch_trends()` 函数调用真实接口
3. 保持输出 JSON 结构与本项目一致

```bash
python3 refresh_trends.py
```

## 数据存储

所有交互数据保存在浏览器 LocalStorage 中，无需后端数据库。更换浏览器或清除缓存会丢失数据。
